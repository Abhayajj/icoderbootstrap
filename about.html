Our Coding Journey

A retrospective of how a simple playground repository evolved into a production-ready template.

April 2024 — Sandbox Initiation

Cloned basic Bootstrap 4 snippets to practice layout grid constructs, forms, and alerts in a sandbox directory.

September 2025 — Adding Templates

Incorporated custom article grids, custom pages (About, Contact), and basic image arrays from stock servers to create prototype sections.

June 2026 — Clean Architecture & Upgrades

Upgraded to Bootstrap 5.3.3, resolved all parsing errors and layout typos, and built a custom dark mode switcher, interactive components, and premium modern developer styling for portfolio launch.
